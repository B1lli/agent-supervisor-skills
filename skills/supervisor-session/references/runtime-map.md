# 宿主对照表

正文只写「要做什么」，不写具体工具名。这里给两个常见宿主的落法。工具名随版本变化，**用之前先确认你手上这版有没有这个能力**；没有就按「退化做法」那列走，纪律不变。

| 要做的事 | Claude Code | Codex CLI | 都没有时的退化做法 |
|---|---|---|---|
| skill 装在哪 | `~/.claude/skills/<name>/SKILL.md`，或仓库内 `.claude/skills/` | `~/.codex/skills/<name>/SKILL.md` | 把 SKILL.md 内容贴进 `AGENTS.md` 或开场提示 |
| 开一条独立干活会话（独立进程、独立 worktree、用户可接管） | 后台任务／会话派发工具 | 新开一个 `codex` 会话；非交互用 `codex exec -C <worktree> "<任务书>"` | 人工开一个终端跑一条，任务书贴进去 |
| 起只读子代理（总管自己消费的盘点、调研、对抗审核） | 子代理工具，选只读档 | `codex exec --sandbox read-only -C <路径> "<问题>"`（加 `--ephemeral` 不落盘） | 总管自己读，但要落盘成文件，别只留在脑子里 |
| 给已有会话追加指令 | 按会话 id 发消息 | `codex resume <session-id> "<指令>"` | 在那条线的终端里直接说 |
| 只读查某条线的进展 | 会话列表／记录检索工具 | 读 `~/.codex/sessions` 下的会话记录；`codex resume` 的选择器可列出会话 | `git log`／`git status`／读数文件的 mtime |
| 撤回还没开始的任务 | 撤回任务卡 | 无对应命令：删掉任务书、不启动那条线 | 同左 |
| 定时巡检 | 会话内定时 + 宿主的定时任务 | `cron` 起一条 `codex exec` | 人工设闹钟 |

**不管哪个宿主，三条不变**：干活线必须是独立会话（不是只读子代理），进展靠只读获取（不靠发消息问），重测试串行由总管自己跑。
